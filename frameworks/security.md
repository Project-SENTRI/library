# AI Security & Adversarial Defense Frameworks

A curated directory of technical standards, threat taxonomies, vulnerability classifications, and red-teaming methodologies designed to secure AI systems against malicious attacks and system failures.

> **Note** > Project SENTRI does not own or publish these frameworks. This directory exists solely to help learners, researchers, and developers navigate technical security standards.

---

| Framework / Standard | Publishing Body | Domain | Focus Area | Description | Official Link |
|----------------------|-----------------|--------|------------|-------------|---------------|
| OWASP Top 10 for LLM Applications | OWASP | Application Security | LLM Vulnerabilities | Comprehensive list of top vulnerabilities (Prompt Injection, Insecure Output Handling, Data Poisoning). | [owasp.org](https://owasp.org/www-project-top-10-for-large-language-model-applications/) |
| MITRE ATLAS (Adversarial Threat Landscape) | MITRE | Adversarial AI | Threat Taxonomy & Attacks | Knowledge base of adversary tactics, techniques, and real-world attack vectors against ML systems. | [atlas.mitre.org](https://atlas.mitre.org/) |
| NIST SP 800-218A (Secure Software / AI) | NIST (US) | Software Supply Chain | DevSecOps & Training Data | Securing the software supply chain and data pipelines specifically for AI/ML models. | [csrc.nist.gov](https://csrc.nist.gov/) |
| CISA / NCSC Guidelines for Secure AI System Development | CISA & UK NCSC | Secure Development | Enterprise Architecture | Global joint guidance on secure design, secure development, secure deployment, and secure operation. | [ncsc.gov.uk](https://www.ncsc.gov.uk/files/Guidelines-for-secure-AI-system-development.pdf) |
| Cloud Security Alliance (CSA) AI Security Initiative | CSA | Cloud & AI Security | Cloud Integration | Best practices for securing AI models deployed within cloud infrastructure and microservice architectures. | [cloudsecurityalliance.org](https://cloudsecurityalliance.org/) |
