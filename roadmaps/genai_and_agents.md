# Phase 3: Generative AI, LLMs & Agentic Systems

This roadmap covers applied Large Language Model engineering, parameter-efficient fine-tuning, retrieval systems, and multi-agent architectures.

---

## 1. Large Language Model (LLM) Fundamentals
* **Architecture:** Causal Language Modeling, Autoregressive Generation, KV Caching, Sampling Parameters (Temperature, Top-P, Top-K).
* **Tokenization:** Byte-Pair Encoding (BPE), WordPiece, Vocabulary building.

## 2. Fine-Tuning & Adaptation
* **Parameter-Efficient Fine-Tuning (PEFT):** LoRA (Low-Rank Adaptation), QLoRA, Prefix Tuning, Adapters.
* **Alignment Tuning:** Instruction Tuning, Direct Preference Optimization (DPO), RLHF (Reinforcement Learning from Human Feedback).

## 3. RAG & Knowledge Retrieval
* **Vector Databases:** Indexing strategies, HNSW, similarity metrics (Cosine, Dot Product).
* **RAG Pipeline:** Document Chunking, Embedding Generation, Hybrid Search (Dense + Sparse/BM25), Re-ranking.

## 4. Agentic AI Systems
* **Agent Loops:** ReAct framework, Plan-and-Solve, Tool/Function Calling.
* **Memory & Execution:** Short-term vs. Long-term memory, Context Window Management, Multi-Agent Coordination.
