# Phase 1: Foundations & Classical Machine Learning

This roadmap covers the prerequisite mathematics, programming foundations, and classical machine learning algorithms aligned with Section 1 of the IOAI syllabus.

---

## 1. Mathematical Foundations
* **Linear Algebra:** Vectors, matrices, matrix multiplication, rank, eigenvalues/eigenvectors, Principal Component Analysis (PCA), SVD.
* **Calculus:** Functions, limits, partial derivatives, gradients, Jacobian/Hessian matrices, chain rule.
* **Probability & Statistics:** Random variables, probability distributions, Bayes' Theorem, expectations, variance, hypothesis testing, maximum likelihood estimation (MLE).

## 2. Core Programming & Tooling
* **Python Basics:** Control flow, OOP, data structures, list comprehensions, file I/O.
* **Data Handling:** NumPy (tensor/array manipulations), Pandas (DataFrames, cleaning, aggregation).
* **Data Visualization:** Matplotlib, Seaborn.
* **ML Libraries:** Scikit-learn, PyTorch tensor basics (CPU/GPU training, seed reproducibility).

## 3. Classical Machine Learning
* **Supervised Learning:**
  * Linear & Logistic Regression (Least Squares, Cost Functions, Regularization: L1 Lasso / L2 Ridge).
  * K-Nearest Neighbors (KNN), Naïve Bayes.
  * Decision Trees, Random Forests, Gradient Boosted Trees (XGBoost, LightGBM).
  * Support Vector Machines (SVMs, Kernel Trick, Margin Maximization).
* **Unsupervised Learning:**
  * Clustering: K-Means, Hierarchical Clustering, DBSCAN.
  * Dimensionality Reduction: PCA, t-SNE, UMAP.
* **Search & Logic (Classical AI):**
  * Uninformed Search (BFS, DFS, Uniform Cost Search).
  * Informed Search (A* Search, Heuristics), Minimax (Game AI).
  * Constraint Satisfaction Problems (CSPs, Backtracking, AC-3).

## 4. Data Processing & Model Evaluation
* **Feature Engineering:** One-hot encoding, scaling/standardization, missing data imputation, train/val/test splits.
* **Metrics:** Accuracy, Precision, Recall, F1-Score, Confusion Matrix, ROC-AUC.
* **Diagnostics:** Bias-Variance tradeoff, Overfitting vs. Underfitting, K-Fold Cross-Validation.
