# AI Security Research Papers

This index covers research on software-level vulnerabilities in machine learning systems, data extraction attacks, supply chain security, and malicious exploitation.

---

## Featured Papers

### 1. Universal and Transferable Adversarial Attacks on Aligned Language Models (2023)
* **Authors:** Andy Zou, Zifan Wang, J. Zico Kolter, Matt Fredrikson
* **Focus:** Jailbreak attacks, adversarial suffixes, LLM safety bypass
* **Description:** Demonstrates automated methods for generating suffix strings that reliably bypass safety filters across multiple open- and closed-source LLMs.
* **Link:** [arXiv:2307.15043](https://arxiv.org/abs/2307.15043)

### 2. Not What You've Signed Up For: Compromising Real-World LLM-Integrated Applications with Indirect Prompt Injection (2023)
* **Authors:** Kai Greshake, Sahar Abdelnabi, Shailesh Mishra, Christoph Endres, Thorsten Holz, Mario Fritz
* **Focus:** Indirect prompt injection, LLM application security, data exfiltration
* **Description:** Introduces threat vectors where untrusted data retrieval (e.g., web browsing, emails) manipulates LLMs into performing unauthorized actions.
* **Link:** [arXiv:2302.12173](https://arxiv.org/abs/2302.12173)

### 3. Extracting Training Data from Large Language Models (2021)
* **Authors:** Nicholas Carlini, Florian Tramer, Eric Wallace, David Jagielski, et al.
* **Focus:** Privacy, training data extraction, memorization
* **Description:** Demonstrates practical methods for extracting verbatim personal data and proprietary text memorized by commercial language models.
* **Link:** [arXiv:2012.07805](https://arxiv.org/abs/2012.07805)
