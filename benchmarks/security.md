# AI Security & Robustness Benchmarks

This section indexes evaluation suites focused on adversarial robustness, backdoor vulnerability detection, secure code synthesis, and cyber-attack simulation.

---

## Featured Benchmarks

### 1. CyberSecEval (Meta)
* **Objective:** Evaluating cyber-attack capabilities and software security risks.
* **Domain:** Vulnerability exploitation, secure code generation, and cyber risk.
* **Description:** A standardized suite measuring LLM capabilities in offensive cyber operations and the safety of generated code against software vulnerability patterns.
* **Link:** [GitHub Repository](https://github.com/meta-llama/PurpleLlama) | [Paper](https://arxiv.org/abs/2312.04724)

### 2. PromptBench
* **Objective:** Robustness under prompt injections, perturbation, and adversarial attacks.
* **Domain:** Input perturbations, prompt injection, and semantic attack surfaces.
* **Description:** A unified evaluation framework designed to systematically analyze model stability against prompt-level attacks, character drops, and malicious injections.
* **Link:** [GitHub Repository](https://github.com/microsoft/promptbench) | [Paper](https://arxiv.org/abs/2306.04528)

### 3. AdvGLUE
* **Objective:** Adversarial robustness across natural language understanding tasks.
* **Domain:** Textual adversarial attacks, perturbation defense, and semantic consistency.
* **Description:** Extends standard language understanding tasks (GLUE) with carefully crafted adversarial perturbations to test model stability against text-level manipulation.
* **Link:** [GitHub Repository](https://github.com/advglue/advglue) | [Paper](https://arxiv.org/abs/2111.02840)

### 4. Inspect (UK AI Safety Institute)
* **Objective:** Automated safety, security, and capability evaluation framework.
* **Domain:** Agentic security, tool use, cyber capabilities, and containment testing.
* **Description:** An open-source evaluation framework developed by the UK AISI for evaluating frontier model capabilities, agent security, and safeguard implementations.
* **Link:** [GitHub Repository](https://github.com/UKGovernmentBEIS/inspect_ai) | [Documentation](https://inspect.ai-safety-institute.org.uk/)
