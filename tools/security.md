# AI Security, Red Teaming & Guardrails Tools

This section indexes tools designed to detect prompt injections, run automated adversarial red teaming, secure deployment pipelines, and enforce output safety guardrails.

---

## Featured Tools

### 1. PyRIT (Python Risk Identification Tool for AI)
* **Developer:** Microsoft
* **Focus:** Automated Red Teaming, Adversarial Probing, AI Security Testing
* **Description:** An open-source automation framework developed by Microsoft's AI Red Team to help security professionals evaluate AI system robustness against adversarial risks and jailbreaks.
* **Link:** [GitHub Repository](https://github.com/Azure/PyRIT)

### 2. NeMo Guardrails
* **Developer:** NVIDIA
* **Focus:** Conversational Safety, Input/Output Filtering, Jailbreak Prevention
* **Description:** An open-source toolkit for adding programmable guardrails to LLM-based applications to control dialogue topics, enforce safety policies, and prevent malicious prompts.
* **Link:** [GitHub Repository](https://github.com/NVIDIA/NeMo-Guardrails)

### 3. Promptfoo
* **Developer:** Promptfoo Team
* **Focus:** Red Teaming, Vulnerability Scanning, Security Benchmarking
* **Description:** A CLI tool and library for automated security scanning, prompt injection testing, red teaming, and capability evaluation across LLM applications.
* **Link:** [GitHub Repository](https://github.com/promptfoo/promptfoo) | [Official Site](https://www.promptfoo.dev/)

### 4. Garak (Generative AI Red-teaming & Assessment Kit)
* **Developer:** Leon Derczynski & Community
* **Focus:** LLM Vulnerability Scanner, Jailbreak Detection, Hallucination Probing
* **Description:** An open-source vulnerability scanner designed to probe LLMs for security bugs, prompt injections, unintended data leakage, and toxic outputs.
* **Link:** [GitHub Repository](https://github.com/leondz/garak) | [Documentation](https://garak.ai/)
