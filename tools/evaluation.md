# AI Evaluation & Benchmarking Tools

This section catalogs frameworks and libraries used to run automated evaluations, benchmark capabilities, test instruction following, and measure performance across AI models.

---

## Featured Tools

### 1. lm-evaluation-harness
* **Developer:** EleutherAI
* **Focus:** Standardized LLM Benchmarking, Zero-Shot & Few-Shot Evaluation
* **Description:** The industry-standard framework for running standardized downstream evaluation tasks across hundreds of datasets (MMLU, GSM8K, ARC, etc.) on local and hosted language models.
* **Link:** [GitHub Repository](https://github.com/EleutherAI/lm-evaluation-harness)

### 2. Inspect
* **Developer:** UK AI Safety Institute (UK AISI)
* **Focus:** AI Safety Evaluation, Agent Capability Testing, Cyber & Autonomy Assessment
* **Description:** An open-source evaluation framework designed to build, run, and scale rigorous safety, security, and capability evaluations for frontier LLMs and agentic systems.
* **Link:** [GitHub Repository](https://github.com/UKGovernmentBEIS/inspect_ai) | [Documentation](https://inspect.ai-safety-institute.org.uk/)

### 3. Ragas (Retrieval Augmented Generation Assessment)
* **Developer:** Exploding Gradients
* **Focus:** RAG Pipeline Evaluation, Faithfulness, Context Precision
* **Description:** A framework that helps evaluate Retrieval Augmented Generation (RAG) pipelines by measuring context recall, faithfulness, answer relevance, and context precision without human annotations.
* **Link:** [GitHub Repository](https://github.com/explodinggradients/ragas) | [Documentation](https://docs.ragas.io/)

### 4. DeepEval
* **Developer:** Confident AI
* **Focus:** CI/CD Testing for LLMs, Unit Testing, Hallucination Detection
* **Description:** An open-source LLM evaluation framework designed like `pytest`, enabling developers to run automated unit tests on LLM outputs for toxicity, bias, hallucination, and metric drift.
* **Link:** [GitHub Repository](https://github.com/confident-ai/deepeval)
