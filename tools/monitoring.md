# AI Monitoring, Tracing & Observability Tools

This section catalogs platforms and libraries built to track model latency, monitor prompt-response behavior, log agent execution trails, and detect real-world output drift.

---

## Featured Tools

### 1. LangSmith
* **Developer:** LangChain
* **Focus:** LLM Tracing, Production Monitoring, Prompt Debugging
* **Description:** A platform designed to trace, test, evaluate, and monitor LLM applications and multi-agent chains from prototype to production environments.
* **Link:** [Official Site](https://www.langchain.com/langsmith) | [Documentation](https://docs.smith.langchain.com/)

### 2. Phoenix (by Arize AI)
* **Developer:** Arize AI
* **Focus:** Open-Source Observability, RAG Tracing, Evaluation Visualizers
* **Description:** An open-source AI observability platform designed for tracing LLM execution, evaluating retrieval quality, visualizing embeddings, and tracking drift.
* **Link:** [GitHub Repository](https://github.com/Arize-ai/phoenix) | [Documentation](https://phoenix.arize.com/)

### 3. OpenTelemetry for AI (OpenInference)
* **Developer:** Arize AI & Open Source Contributors
* **Focus:** Open Tracing Standards, Agentic Observability, Telemetry
* **Description:** An open standard semantic convention for tracing LLM requests, vector store retrievals, and agentic workflows using OpenTelemetry standards.
* **Link:** [GitHub Repository](https://github.com/Arize-ai/openinference)

### 4. Evidently AI
* **Developer:** Evidently AI
* **Focus:** ML Model Monitoring, Data Drift Detection, LLM Quality Checks
* **Description:** An open-source Python library for evaluating, testing, and monitoring machine learning models and LLM systems in production through automated dashboard reports.
* **Link:** [GitHub Repository](https://github.com/evidentlyai/evidently) | [Official Site](https://www.evidentlyai.com/)
