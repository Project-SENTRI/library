# General & Foundation Datasets

A curated collection of foundational datasets used for general machine learning training, multi-task understanding, and natural language processing.

> **Note:** Project SENTRI does not host or own these datasets. This directory links directly to official sources and original creators.

---

| Dataset | Primary Domain | Purpose / Task | License | Source / Provider | Link |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **MMLU** | Multi-Task NLP | Measuring general knowledge across 57 subjects (STEM, Humanities, Social Sciences). | MIT License | UC Berkeley | [Hugging Face](https://huggingface.co/datasets/cais/mmlu) |
| **Common Crawl** | Web Data | Massive web scrape corpus used to train large foundation models. | Terms of Use | Common Crawl Org | [Official Site](https://commoncrawl.org/) |
| **The Pile** | General Text | 825 GB open-source language modeling dataset combined from 22 diverse sources. | MIT License | EleutherAI | [Official Site](https://pile.eleuther.ai/) |
| **RedPajama-Data** | Open Pre-training | Fully open-source multi-trillion token dataset created for training foundation models. | Apache 2.0 | Together AI | [GitHub](https://github.com/togethercomputer/RedPajama-Data) |
| **ImageNet** | Computer Vision | Benchmark image dataset containing over 14 million annotated images across thousands of categories. | Non-Commercial / Research | Stanford University | [Official Site](https://www.image-net.org/) |
