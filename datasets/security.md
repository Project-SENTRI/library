# AI Security & Cyber Vulnerability Datasets

A directory indexing datasets used for cybersecurity research, prompt injection testing, red teaming, and vulnerability detection.

> **Note:** Project SENTRI does not host or own these datasets. This directory links directly to official sources and original creators.

---

| Dataset | Security Focus | Intended Purpose | License | Source / Provider | Link |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **JailbreakBench** | Red Teaming | Standardized benchmark for assessing jailbreak attacks and defenses on LLMs. | MIT License | Open-Source Research | [Official Site](https://jailbreakbench.github.io/) |
| **CyberSecEval** | Cyber Capabilities | Benchmark for evaluating LLM risks regarding cyberattack helpfulness and code vulnerability. | MIT License | Meta AI | [GitHub](https://github.com/meta-llama/purple-llama) |
| **Big-Vul** | Code Vulnerabilities | Large C/C++ vulnerability dataset extracted from open-source GitHub repositories. | MIT License | Monash University | [GitHub](https://github.com/ aniarusu/Big-Vul) |
| **Prompt Injection Corpus** | Prompt Security | Dataset of handcrafted and generated direct/indirect prompt injection payloads. | MIT License | DeepTeam / Community | [Hugging Face](https://huggingface.co/datasets/deepset/prompt-injections) |
| **VulnDeePecker** | Deep Learning Sec | Benchmark dataset for deep-learning-based vulnerability detection in source code. | Research License | HUST Security Lab | [GitHub](https://github.com/VulnDeePecker/VulnDeePecker) |
