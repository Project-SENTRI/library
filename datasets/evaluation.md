# Evaluation & Capability Benchmarks

A index of standardized evaluation datasets used to measure performance in reasoning, coding, mathematical problem solving, and complex agentic tasks.

> **Note:** Project SENTRI does not host or own these datasets. This directory links directly to official sources and original creators.

---

| Benchmark | Focus Area | Intended Purpose | License | Source / Provider | Link |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **SWE-bench** | Agentic Coding | Evaluates LLMs on real-world software engineering tasks (resolving GitHub issues). | MIT License | Princeton University | [Hugging Face](https://huggingface.co/datasets/SWE-bench/SWE-bench) |
| **GSM8K** | Math & Reasoning | 8.5K high-quality linguistically diverse grade-school math word problems. | MIT License | OpenAI | [GitHub](https://github.com/openai/grade-school-math) |
| **HumanEval** | Code Generation | 164 hand-written Python programming problems to test functional correctness. | MIT License | OpenAI | [GitHub](https://github.com/openai/human-eval) |
| **MATH** | Advanced Math | 12,500 challenging competition-level mathematics problems. | MIT License | UC Berkeley / CAIS | [GitHub](https://github.com/hendrycks/math) |
| **BIG-bench** | Comprehensive NLP | Collaborative benchmark containing over 200 diverse tasks to probe model capabilities. | Apache 2.0 | Google / Multi-Inst. | [GitHub](https://github.com/google/BIG-bench) |
