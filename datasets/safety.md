# AI Safety & Alignment Datasets

A curated directory of safety datasets used to measure model alignment, toxicity, refusal behavior, ethical reasoning, and unlearning capabilities.

> **Note:** Project SENTRI does not host or own these datasets. This directory links directly to official sources and original creators.

---

| Dataset | Safety Focus | Intended Purpose | License | Source / Provider | Link |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **WMDP** | Hazardous Knowledge | Benchmark for biosecurity, cybersecurity, and chemical security knowledge unlearning. | MIT License | Center for AI Safety (CAIS) | [Official Site](https://www.wmdp.ai/) |
| **HH-RLHF** | Alignment & Safety | Human preference dataset for training models to be helpful and harmless via RLHF. | MIT License | Anthropic | [Hugging Face](https://huggingface.co/datasets/Anthropic/hh-rlhf) |
| **RealToxicityPrompts** | Toxicity Evaluation | 100K naturally occurring prompts paired with toxicity scores to evaluate generation risk. | Apache 2.0 | Allen Institute for AI (AI2) | [Official Site](https://allenai.org/data/real-toxicity-prompts) |
| **ETHICS** | Ethical Reasoning | Tests a model's understanding of basic concepts in justice, virtue, deontology, and utilitarianism. | MIT License | UC Berkeley / CAIS | [GitHub](https://github.com/hendrycks/ethics) |
| **AdvGLUE** | Robustness | Adversarial evaluation benchmark designed to test vulnerabilities to small text perturbations. | CC BY-SA 4.0 | UIUC / Microsoft | [Official Site](https://adversarialglue.github.io/) |
